# CloudField 功能需求与演进路线图

> 本文档汇总对 CloudField 体积云微物理诊断工具的能力盘点与增强建议，按"诊断能力 / 微物理模块 / 数据接入 / 工程与协作 / 用户体验"五个维度组织，共 14 项。每项给出**现状缺口**与**具体建议**，作为后续版本演进的需求基线。

## 一、诊断能力：从"点"到"线"和"面"

### 1. 时变与预报对接
- **现状缺口**：当前为单次场景诊断，缺少时间序列驱动（模式输出、实况序列的逐时推进）；看不到"能见度随时间演变曲线"，也无法让场景参数随预报时次自动推进。
- **建议**
  - 增加时间轴（timeline）+ 循环播放控件；
  - 支持导入时序探空（time-series sounding）与时序 METAR；
  - 场景参数（温度 / 湿度 / 风 / 云参）随预报时次自动插值推进。

### 2. 空间对比与统计
- **现状缺口**：仅有单点能见度读数（如 202 m），缺少水平面上的能见度场二维色块图；缺统计口径：云量覆盖率、云顶 / 云底高度、光学厚度垂直积分、水平平均消光廓线。
- **建议**
  - 底部新增"水平能见度场"面板（二维色块 / 等值线）；
  - 新增统计量卡片组：总云量覆盖率、云顶高度、云底高度、垂直积分光学厚度、水平平均消光廓线。

### 3. 多诊断量并行
- **现状缺口**：当前以能见度为单目标；未覆盖散射 / 吸收分离、太阳 / 天空辐照度、云反照率、卫星可见光通道亮温模拟、激光雷达 / 微波雷达回波模拟。
- **建议**：将上述量建模为同一微物理场的"观测算子"（observation operators），作为科研版本的核心价值；提供多算子并行开关与图层叠加。

## 二、微物理模块：补全体谱信息

### 4. 粒子谱描述
- **现状缺口**：仅"有效半径 + 数浓度"两个参数，等价于把谱压成 Gamma 谱形状参数、仅决定两个矩；同一有效半径下真实消光可差不少。
- **建议**：增加谱型选择（Gamma / 对数正态 / 实测谱导入），并展示各谱矩（如有效半径、有效方差、数浓度、液态水含量）。

### 5. 相态与分档
- **现状缺口**：仅云水 / 云滴，无冰相（冰晶、雪、霰、雹）、无水冰混合、无气溶胶背景；冰晶消光 / 散射特性与云滴差异大，直接影响可见光能见度与卫星观测。
- **建议**：增加相态分档开关（云滴 / 冰晶 / 雪 / 霰 / 雹）+ 水冰混合比例 + 气溶胶消光背景项。

### 6. 敏感性分析自动化
- **现状缺口**：滑块为手调，看不到响应曲线。
- **建议**：内置"参数扫描 + 自动出图"：对 N、有效半径、LWC 等做二维敏感性热力图（如能见度 / 光学厚度随双参数网格变化）。

## 三、数据接入：质控与双向

### 7. 数据质控（QC）
- **现状缺口**：METAR / 探空导入后未做合理性检查、缺测处理、异常值标记；跨源时间戳对齐、坐标系统一未体现。
- **建议**：导入后弹出 QC 报告，标注可疑值与缺测；做时间戳对齐与坐标系统一（如 UTC 归一、WGS-84）。

### 8. 业务系统输出
- **现状缺口**：当前以"读入"为主；WebSocket 有连接与模拟推送，但未把诊断结果按标准格式（BUFR、GRIB、IWXXM、AVMET）输出。
- **建议**：增加导出为标准行业报文 / 推送至 API 服务端点的能力。

### 9. 验证与误差评估
- **现状缺口**："探空验证"仅为表格对比，缺偏差、均方根误差、泰勒图、散点图、时间序列对比。
- **建议**：新增"模型 vs 观测"验证面板（图表化）：偏差、RMSE、泰勒图、散点、时间序列对比。

## 四、工程与协作

### 10. 批处理与自动化
- **现状缺口**：一次只能调一个场景；缺批量导入机场列表 / 批量跑多个时次 / 命令行或脚本调用。
- **建议**：提供 CLI 或 Python SDK，支持无人值守批量诊断（机场列表 × 时次矩阵）。

### 11. 场景复现
- **现状缺口**：事件录制有时间轴但事件数为 0，说明录制功能可能未启用或粒度不足。
- **建议**：记录完整参数快照 + 每一步操作，支持精确回放（参数级 + 操作级）。

### 12. 协作与分享
- **现状缺口**：导出 JSON 为原始数据，缺一键生成报告（PDF / HTML）、截图标注、分享链接。
- **建议**：增加"导出诊断报告"模板（含图表、参数、结论），支持截图标注与分享链接。

## 五、用户体验细节

### 13. UI 层小毛病
- **现状缺口**：数值单位有时缺失或不统一（m / km、mg/m³ / g/m³）；能见度 202 m 多次出现疑似固定展示值，需明确"实时计算值还是示例值"。
- **建议**：所有读数统一单位规范 + 加 tooltip 说明公式与口径；明确标注示例 / 实时来源。

### 14. 帮助与教学
- **现状缺口**：公式有展示但缺参数说明、缺"滑块改动后物理含义"引导。
- **建议**：内置参数释义卡片 + 示例场景（浓雾、层云、积云、冰云）。

## 实施分期建议（参考）
- **近期（体验与正确性）**：#13 单位规范与 tooltip、#14 参数释义卡片与示例场景、#7 数据 QC 报告。
- **中期（诊断深度）**：#1 时间轴与循环播放、#2 水平能见度场与统计量、#4 / #5 谱型与相态分档、#9 验证面板。
- **远期（科研与业务）**：#3 多观测算子、#6 敏感性扫描、#8 标准报文输出、#10 CLI / SDK、#11 场景复现、#12 报告与协作。
